# Implementation roadmap

1. Choose the product problem, intended users, AI workflow, and success metrics.
2. Choose the technology stack and architecture. Set up a runnable project.
3. Build request submission, discovery, and support.
4. Implement the chosen AI workflow and show how requests are grouped, evaluated, or prioritized. Define where people make decisions.
5. Run the system locally and check the main user flows. Document setup, decisions, risks, and tradeoffs.
6. Prepare the public repository and a roughly five-minute demonstration for submission.

The assessment suggests two or three success metrics and an estimated working time of two to three hours. The order and scope remain subject to the project owner's direction.
